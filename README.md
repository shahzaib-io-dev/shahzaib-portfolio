## ◈ 01 — The Vision

Portfolio V1 is a single-page frontend experiment built from scratch with **HTML5, CSS3, and Vanilla JavaScript**. The goal was to explore how motion, cursor interactions, and unusual scrolling patterns can make a developer portfolio feel more engaging.

This version focuses on the experience and visual experimentation. It is a learning project, and the next version will place more emphasis on project case studies, content, and a clearer multi-page structure.

### Interactive features

<p align="center">
  <img src="assets/interactive-features.png" width="100%" alt="Interactive features and motion effects in the portfolio">
</p>

- **Canvas particle network:** an animated network effect created with the Canvas API.
- **Custom cursor:** a dual-layer cursor with contextual text for interactive elements.
- **Horizontal project browsing:** selected sections use vertical-to-horizontal scrolling to present projects and experiments.
- **Cursor-following spotlight:** cards respond to cursor movement with a focused lighting effect.
- **Scroll reveal animations:** elements appear as they enter the viewport using the Intersection Observer API.
- **Hero image reveal:** the hero portrait transitions from grayscale to color on hover.

## ◈ 03 — Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic content |
| CSS3 | Layout, responsive styling, transitions, and animations |
| Vanilla JavaScript | Cursor interactions, scrolling behavior, and dynamic effects |
| Canvas API | Particle-network visual effect |
| Intersection Observer API | Scroll-triggered reveal animations |

No React, Vue, Tailwind CSS, or jQuery was used in this version.

## ◈ 04 — Design Philosophy

- **Interaction with purpose:** effects are intended to support exploration rather than act only as decoration.
- **Motion-led presentation:** scrolling, hover states, and reveals are part of the overall experience.
- **Built from scratch:** the project uses standard web technologies without a frontend framework.
- **Experimental by design:** V1 is a place to test ideas and learn what should be improved in a future version.

## ◈ 05 — V1 vs. What's Next

V2 is a planned direction, not a feature set already included in V1.
